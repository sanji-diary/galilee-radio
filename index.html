방송 자막

    DJ는 AI입니다. 성경 구절은 직접 확인해 주세요. 힘들 땐 109(24시간)·목회자와 이야기해 주세요.

    DJ가 어떻게 불러 드릴까요?

    애칭을 적으면 DJ가 "○○님" 하고 불러 드려요. 비워 두면 "청취자님"이라고 불러요.

    방송이 잘 안 될 때

    DJ와는 🎙 눌러서 말하기로 이야기해요. 버튼을 누르고 말한 뒤, 다 말했으면 한 번 더 누르세요. 마이크가 꺼져 있는 동안에는 주변 소리가 DJ를 방해하지 않아요. 글로 보내도 돼요.

    마이크 허용 창이 계속 떠요

    • 아이폰(사파리): 주소창 왼쪽 가가(또는 aA) → 웹 사이트 설정 → 마이크 → 허용
    • 아이폰 설정: 설정 앱 → Safari → 마이크 → 허용
    • 안드로이드(크롬): 주소창 왼쪽 자물쇠 → 권한 → 마이크 → 허용
    • 홈 화면에 추가한 앱이라면, 설정을 바꾼 뒤 앱을 완전히 닫았다가 다시 열어 주세요.

    블루투스 이어폰

    • 이어폰을 먼저 연결한 뒤 방송을 시작해 주세요. 방송 중에 연결하면 소리가 휴대폰 스피커로 나올 수 있어요.
    • 마이크를 쓰는 동안 블루투스 이어폰은 '통화 모드'로 바뀌어 음질이 조금 낮아질 수 있어요. 정상이에요.
    • 소리가 안 나오면 방송을 끄고 이어폰을 다시 연결한 뒤 다시 시작해 주세요.

    DJ가 말을 안 해요

    • 시끄러운 곳이라면 말하기 버튼을 끈 상태에서 기다려 주세요.
    • 와이파이나 데이터 연결을 확인하고, 방송을 껐다가 다시 켜 주세요.
